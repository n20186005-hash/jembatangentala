# Gentala Arasy independent visitor guide

This repository intentionally contains deployable static HTML and assets at its root, not an unpublished framework source project. Edit both Indonesian and English pages directly. No package installation or framework build is required. Cloudflare Workers binds this root as ASSETS with Worker-first execution; worker.js handles canonical redirects and response headers. Keep deployment metadata excluded through .assetsignore.

The two language homepages and six legal pages have server-rendered HTML. Check metadata, matching visible FAQ/schema, local references, sitemap, consent storage exceptions, and Worker redirect/404 behavior before deployment. Browser layout and interaction still require a separate visual review.

Public place snapshots were checked on 19 October 2026. Google Maps bridge hours and accessibility are dated third-party listings, not unconditional access promises. Museum profile hours and price apply only to that separately managed museum and require reconfirmation. See linked primary sources on each homepage.

The three photographs are Firzafp’s 2023 works on Wikimedia Commons, licensed CC BY-SA 4.0. Source and licence links accompany every gallery photograph. Local versions are resized WebP conversions; CSS can crop display. Adaptations remain under CC BY-SA 4.0. Photographs document past views, not current access conditions. Hosting/analytics details and storage failure behavior are described in both language privacy and cookie pages. Old service worker caches are retired only within the jga- namespace.
