Kebijakan Privasi

Panduan ini tidak memiliki akun, pemesanan, formulir kontak, atau alamat email untuk mengirim data pribadi. Penyedia hosting dapat memproses log teknis seperti alamat IP, waktu, peramban, dan permintaan halaman untuk pengiriman dan keamanan situs. Hosting juga dapat menyisipkan skrip Cloudflare Web Analytics secara terpisah untuk mengukur waktu pemuatan dan kinerja halaman. Layanan ini terpisah dari pilihan Google Analytics di situs ini; menolak Google Analytics di sini tidak menonaktifkan analitik hosting tersebut. Google Analytics dimuat hanya setelah izin analitik eksplisit melalui pengaturan kuki; data penggunaan dan pengenal kuki dapat dikirim ke Google. Tidak ada peta tersemat, font eksternal, atau permintaan cuaca otomatis. Membuka tautan eksternal menghubungi penyedia tujuan dengan kebijakan mereka sendiri. Preferensi analitik tersimpan secara lokal; penolakan sesi menggunakan sessionStorage. Jika penyimpanan gagal, status menjelaskan apakah penolakan berlaku untuk tab atau hanya halaman ini. Kami tidak mengklaim pilihan permanen tersimpan bila gagal. Hapus data situs melalui pengaturan peramban untuk menghapus izin lama. Pilihan analitik dari versi situs lama tidak diaktifkan otomatis pada versi ini.
